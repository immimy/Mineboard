## Database

Supabase (PostgreSQL). Accessed via GraphQL — not direct SQL or Supabase's JS query builder.

## Supabase client factories

Two environments, two factories — both in `utils/database/`:

- `serverClient.ts` → `createClient()` — for server components, route handlers, server actions. Uses `createServerClient` from `@supabase/ssr` with Next.js `cookies()`.
- `browserClient.ts` → `createClient()` — for client components. Uses `createBrowserClient` from `@supabase/ssr`.

Both need `NEXT_PUBLIC_SUPABASE_PROJECT_URL` and `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` (validated in `utils/database/config.ts` — throws at startup if missing).

## JSONB field types

List fields store structured data as JSONB in the database. The TypeScript types for all JSONB shapes are defined in `types/jsonbSchema.ts`:

| Type | Config shape | Value shape |
|---|---|---|
| `TextSchema` | `{ title }` | `string` |
| `NumberSchema` | `{ title, isHasUnit, unit, unitPosition }` | `string` |
| `DateSchema` | `{ title, isIncludeTime }` | `string` |
| `ImageSchema` | `{ title }` | `string[]` |
| `CheckboxSchema` | `{}` | `{ checked, title }` |
| `TagSchema` | `{ color: ColorPalette }` | `{ tag, color? }[]` |

All schemas follow `JsonbSchemaBase<TConfig, TValue> = { config: TConfig; value: TValue }`.

The union type `ListField` covers all six variants.

## Color palette

`ColorPalette` enum in `types/jsonbSchema.ts` maps names (first–ninth) to integers 1–9. This numeric value is stored in the database and used to look up dynamic CSS classes (see styling rules).

## Generated GraphQL types

Types generated by codegen live in `gql/__generated__/graphql.ts`. Import from `@/gql/__generated__` — never from the raw file path.
